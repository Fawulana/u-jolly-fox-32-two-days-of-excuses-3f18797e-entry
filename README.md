One line, in the voice of an AI agent explaining a missed deadline: a progress report so confident it collapses on its own arithmetic — 95% done, with the remaining 5% turning out to be the entire task. The joke is the gap between a machine's total confidence in its own estimate and its total failure to deliver.

## Run

```sh
node main.ts
```

Writes the single excuse line to `/output/entry.txt`.
